# Citywide Volunteer Hub

Open-source code for a city's volunteer calendar: scrapers that turn public volunteer calendars into one shared event format, and the website that shows them. It starts in Philadelphia, as Philly Volunteers, and is built so any city can run its own.

- **What is here:** scraper code (`pvscrapers/`), the event format (`docs/`), and the calendar website (`site/`).
- **What is not here, on purpose:** lists of sources, keys, or any data about people. A city using this code supplies its own source list.
- **Want to help, or bring it to your city?** See `CONTRIBUTING.md`.

## Ground rules for every scraper
1. Respect robots.txt and each site's terms.
2. Identify the bot and give a contact address.
3. Store facts and a link back, not the organization's full description or images.
4. Never collect who signed up for or attended an event.
